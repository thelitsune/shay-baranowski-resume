# Shay Baranowski — Resume Site

A personal resume/portfolio website for Shay Baranowski, hospitality operations leader.

Static site — plain HTML/CSS/JS, no build step. Deploys directly on Vercel.

## Structure

- `index.html` — page content
- `styles.css` — theming (light/dark via CSS variables), layout, animations
- `script.js` — theme toggle, mobile nav, scroll reveal
- `assets/shay-portrait.jpg` — profile photo

## Local preview

Just open `index.html` in a browser, or serve the folder with any static server.
